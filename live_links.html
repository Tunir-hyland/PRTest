🔍 GitHub PR Review Agent - Live Links

⚡ Quick Start

1. Install Python from Microsoft Store

2. Restart PowerShell

3. Click any PR link below or run the command

💻 Commands - Copy & Run in PowerShell

python pr_review_agent.py https://github.com/microsoft/vscode/pull/200000
python pr_review_agent.py https://github.com/facebook/react/pull/25000
python pr_review_agent.py https://github.com/golang/go/pull/65000

For Private Repos:

$env:GITHUB_TOKEN="your_token_here"
python pr_review_agent.py https://github.com/your-org/your-repo/pull/123

🎯 What You'll Get

  • ✅ Summary - Files changed, lines added/removed
  • 🐛 Bug Detection - Hardcoded credentials, debug statements, empty catches
  • 💡 Improvements - Large functions, complex logic, modern syntax suggestions
  • 📝 TODOs - All TODO, FIXME, HACK comments
  • 📏 Large Methods - Methods over 50 lines flagged
  • 🔄 Duplicates - Repeated code detection
  • 📰 Release Notes - Auto-generated changelog

🔑 Get GitHub Token (Optional)

For private repos or higher rate limits:

→ Generate Token at GitHub Settings

Select scope: repo (for private) or public_repo (for public only)
